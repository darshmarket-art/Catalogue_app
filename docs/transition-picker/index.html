Performance
    
      
  • Every transition animates transform and opacity only. No blur, no layout, no paint per frame.
    • 
      
  • Runs on the compositor via the Web Animations API with a spring-shaped easing, 500 to 800 ms at 1x.
    • 
      
  • Tile and fold options use a few cloned layers for the duration of the move, then remove them.
    • 
    

    
Behaviour
    
      
  • Direction follows tab order: moving right turns forward, moving left turns back.
    • 
      
  • Interruptible: a new tap cancels the move in flight and starts the next from the settled page.
    • 
      
  • Perspective is scaled to the screen so phone and desktop feel the same.
    • 
    

    
Reduced motion
    
      
  • When a visitor's device requests reduced motion, every option falls back to a 160 ms cross-fade (option 13).
    • 
      
  • No translation, rotation or scale remains in that path.
